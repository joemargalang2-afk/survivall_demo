# SURVIVALL

Version 0.9.1 "Defense Demo" (2026-10-13)

## How to open it

- Open the game's web address in Chrome, on a laptop or on an Android phone.
- On a phone, hold it sideways and tap once on the game for fullscreen.
- To keep it like an app: Chrome menu (⋮) → Install. After the first visit it also works without internet.
